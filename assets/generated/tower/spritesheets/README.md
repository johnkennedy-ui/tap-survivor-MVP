# Tower Sprite Sheets

User-provided Telegram images for the 2026-06-21 enemy and boss pack arrived as JPEGs with a baked checkerboard background. Runtime PNGs in this folder were prepared with `npm run spritesheets:prep` using ffmpeg colorkey cleanup.

Enemy sheet:
- `enemies-tower-pack.png`
- 8 rows, 6 frames per row
- rows: drifter, skitter, bulwark, hexer, verdant_skitter, dusk_crawler, crimson_hexer, obsidian_bulwark

Boss sheet:
- `bosses-tower-pack.png`
- 3 rows, 9 frames per row
- rows: warden, charger, turret
