The app stores local game progress on the device/browser so the player can continue playing. This may include game state such as progress, unlocks, settings, and save data.

This finding is based on the current repo inspection. It must be reviewed again before publication and whenever dependencies, Android plugins, network features, or third-party services change.

## Local storage

On Android, the app may use Capacitor Preferences or equivalent local storage to store game progress on the device.

On the web/GitHub.io tester, the app may use browser localStorage to store game progress in the browser.

This local game progress is intended to remain on the user's device/browser and is not intentionally transmitted to the developer by the current app.
