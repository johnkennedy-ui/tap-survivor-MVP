# Enemy Progression Content Slice

## Request

Slice 1 from the enemy progression task: add more enemy types and vary movement speed, size, projectile tuning fields, sprite palette, and tower-floor introductions.

## Scope

- Content-only enemy progression patch.
- No runtime mechanic changes in this slice.
- Fixed-HP runtime behavior, suitability guard changes, and visual tint/ring polish remain later slices.

## Implementation

- Expanded enemy roster from 4 to 8:
  - floor 1: `drifter`
  - floor 2: `skitter`
  - floor 3: `bulwark`
  - floor 4: `hexer`
  - floor 5: `verdant_skitter`
  - floor 6: `dusk_crawler`
  - floor 7: `crimson_hexer`
  - floor 8: `obsidian_bulwark`
- Added `minTowerFloor` to the existing early enemies so tower-floor introductions are explicit.
- Added sprite mappings that move from brighter/greener early enemies toward black/red later enemies.
- Added varied speed/radius/HP/damage/XP values in content.
- Added projectile tuning fields to ranged enemies:
  - `projectileCooldown`
  - `projectileSpeed`
  - `projectileDamage`
  - `projectileRadius`
  - `projectileColor`
- Updated all timed wave level entries to include the full enemy ladder; current runtime filtering by `minTowerFloor` controls eligibility.
